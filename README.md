# SIAP-BE

A Next js Frotend.

## Prerequisites

Before running this application, ensure you have the following installed:

- **Node**: 24.x
- **pnpm**: 10.x

## Getting Started

```bash
pnpm install
pnpm dev
```

## Environment Variables

Create a `.env` file in the root directory with the following variables:

```dotenv
NEXT_PUBLIC_API_BASE_URL=
```
